# E-Commerce Customer & Revenue Analysis

## Overview

This project explores e-commerce sales, customer behavior, product performance, and delivery trends using the Brazilian E-Commerce Public Dataset by Olist. The goal is to use SQL to answer business questions and identify areas for improvement.

## Tools
- MySQL
- MySQL Workbench
- GitHub

## Dataset

The dataset contains approximately 100,000 orders placed between 2016 and 2018 across nine related tables.

[Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

## Business Questions

1. How does revenue change over time?
2. What is the average order value?
3. Which product categories generate the most revenue?
4. Which states generate the most sales?
5. Which payment methods are used most frequently?
6. How long does delivery take on average?
7. How many orders are delivered on time versus late?
8. How does delivery performance relate to customer reviews?
9. How many customers place repeat orders?
10. Which sellers generate the most revenue?
11. How does revenue change month over month?

## SQL Concepts Used

- Joins and aggregate functions
- Subqueries
- Group By and Having
- Case statements
- Common table expressions (CTEs)
- Window functions (RANK and LAG)
- Stored procedures
- Triggers
