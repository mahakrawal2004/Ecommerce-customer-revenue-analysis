# Resume Bullets

Use one or two of these depending on available space.

- Analyzed approximately 100K e-commerce orders using MySQL to evaluate revenue trends, product performance, customer behavior, payments, delivery performance, and review scores across nine relational tables.
- Built SQL analyses using joins, CTEs, subqueries, case statements, and window functions to identify top revenue categories, repeat customers, seller performance, and month-over-month revenue trends.
- Designed a Power BI dashboard to track revenue, average order value, product categories, geographic performance, delivery timing, payment methods, and customer satisfaction.
- Evaluated the relationship between delivery performance and customer reviews, finding substantially lower review scores for late deliveries compared with on-time orders.
